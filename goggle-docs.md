
# Google Docs for Collaborative Technical Writing

## 1. Introduction

Google Docs is a cloud-based word processor available through Google Workspace. It allows users to create, edit and share documents online.

Multiple users can work on the same document simultaneously, making it useful for assignments, reports, meeting notes and project documentation.

### Uses of Google Docs

- Creating technical reports and assignments.
- Collaborating with multiple users.
- Preparing project proposals.
- Editing and reviewing documents.
- Sharing documents online.

## 2. Main Features

Some important features of Google Docs include:

1. Real-time collaboration.
2. Automatic saving.
3. Document formatting.
4. Comments and suggestions.
5. Version history.
6. Templates for different documents.
7. Importing and exporting documents.
8. Inserting images, tables and equations.

## 3. Creating and Structuring a Document

A document can be created using a blank page or an existing template.

### Steps

1. Open Google Docs.
2. Select Blank Document.
3. Enter the document title.
4. Add the required content.
5. Apply suitable formatting.
6. Organize content using headings and subheadings.

### Heading Styles

Google Docs provides different heading styles:

| Style | Purpose |
|---|---|
| Title | Main document title |
| Subtitle | Supporting title |
| Heading 1 | Main sections |
| Heading 2 | Subsections |
| Normal Text | Regular paragraphs |

Using heading styles helps maintain consistency and allows automatic generation of a table of contents.

## 4. Collaboration and Sharing

Google Docs allows multiple users to work on the same document in real time.

The Share option allows users to invite collaborators through email or a sharing link.

### Access Permissions

There are three main access roles:

| Role | Permission |
|---|---|
| Viewer | Can only view the document |
| Commenter | Can view and add comments |
| Editor | Can view and modify the document |

### Comments and Suggestions

- Comments allow users to provide feedback.
- Suggesting mode allows reviewers to propose edits.
- Comments can be assigned and resolved.
- Multiple users can see changes while collaborating.

## 5. Version History

Google Docs automatically saves changes made to a document.

Version history allows users to view previous versions and restore an earlier version if required.

### Steps to View Version History

1. Open the document.
2. Click File.
3. Select Version history.
4. Click See version history.
5. Select the required version.

Important versions can also be given names to identify milestones such as submission drafts and approved copies.

## 6. Images, Drawings, Tables and Lists

Google Docs supports different elements for organizing information.

### A. Images

Images can be inserted using:

Insert → Image

Users can select an image from available sources.

### B. Drawings

The Insert → Drawing option allows users to create simple diagrams using shapes, lines and arrows.

### C. Tables

Tables help organize and compare information in rows and columns.

They can be inserted using:

Insert → Table

### D. Lists

Google Docs supports:
- Bulleted lists.
- Numbered lists.
- Checklists.

These features help organize information clearly.

### Diagrams

For more detailed diagrams, integrations such as Lucidchart and diagrams.net can be used.

## 7. Equations and Code

Google Docs provides an equation editor for writing mathematical expressions.

### Inserting Equations

1. Open the document.
2. Select Insert.
3. Click Equation.
4. Enter the mathematical expression.

The equation editor supports basic LaTeX-style mathematical input through its interface.

### Formatting Code

Short code snippets can be formatted using a monospace font.

Larger code blocks may require an add-on or another suitable formatting method.

## 8. Templates and Formatting

Google Docs provides built-in templates for reports, proposals and other documents.

Users can customize:

- Fonts and text sizes.
- Paragraph alignment.
- Headers and footers.
- Page numbers.
- Margins and spacing.

Additional tools include:
- Find and Replace.
- Spelling and grammar checking.
- Document formatting.

Templates provide a starting point, but the final document should always be proofread.

## 9. Citations and Bibliography

Google Docs provides a citation tool for managing references.

It can be accessed through:

Tools → Citations

### Supported Citation Styles

- MLA
- APA
- Chicago

### Features

1. Adding sources.
2. Inserting in-text citations.
3. Generating bibliographies.
4. Managing references.

Integrations such as Zotero and Mendeley can also help manage references.

Borrowed ideas, figures and quotations should always be acknowledged using the required citation style.

## 10. Exporting and Publishing

Google Docs allows users to download documents in different formats.

Common formats include:

- PDF
- DOCX
- ODT
- HTML
- RTF
- TXT

Documents can also be published to the web when public access is required.

Before sharing a document, users should check its access permissions.

## 11. Security and Permissions

Google Docs provides document-level sharing permissions.

Important security practices include:

- Give collaborators only the access they require.
- Review who can access the document.
- Avoid making private documents public.
- Check sharing links before distributing them.

Organization administrators may also control sharing policies.

## 12. Best Practices

- Use consistent formatting and templates.
- Organize content with headings.
- Create a table of contents for long documents.
- Use comments and suggestions for reviews.
- Assign appropriate editing permissions.
- Resolve comments after addressing feedback.
- Name important document versions.
- Check sharing permissions before distributing links.
- Proofread the final document.

## 13. Doxygen vs Google Docs

| Feature | Doxygen | Google Docs |
|---|---|---|
| Purpose | Code and API documentation | General documents and reports |
| Collaboration | Usually through code review | Real-time editing |
| Rich Media | Code-linked diagrams and examples | Images, tables and drawings |
| Output | HTML, LaTeX/PDF and others | Web, PDF, Word and others |
| Best For | Source code and APIs | Notes, proposals and specifications |

Both tools can be used together in a software project.

Google Docs can be used for design notes and reports, while Doxygen can generate API documentation.
